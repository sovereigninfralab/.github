# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately. Do not open a public issue.

Use GitHub private vulnerability reporting: open the affected repository, select the **Security** tab, then **Report a vulnerability**. A dedicated security email address will be added to this policy when it is available.

Please include the affected repository and version or commit, a description of the issue, and steps to reproduce it.

SISL will acknowledge a report within five business days, keep the reporter informed while the issue is investigated and fixed, and credit the reporter in the advisory unless they prefer otherwise.

## Supported versions

No releases have been published yet. Once releases exist, security fixes will be made for the latest release.
