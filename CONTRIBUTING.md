# Contributing

Thank you for your interest in SISL's projects.

## Before you start

- For anything larger than a small fix, please open an issue first so the approach can be agreed before you spend time on it.
- Security problems must not be reported in public issues. See SECURITY.md.

## Pull requests

- Changes reach the `main` branch only through pull requests.
- Keep each pull request focused on one change and describe what it changes and why.
- Sign off each commit to certify the [Developer Certificate of Origin](https://developercertificate.org/): `git commit -s`.

## Licensing of contributions

Contributions are accepted under the license of the repository they are made to: Apache License 2.0 for code, Creative Commons Attribution 4.0 International (CC BY 4.0) for documents and reference architectures.

## What not to contribute

Do not submit confidential information that belongs to an employer, client or any other third party, and do not commit credentials, keys or other secrets.
