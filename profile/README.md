# Sovereign Infrastructure Software Lab, LLC

Sovereign Infrastructure Software Lab, LLC (SISL) is based in Ashburn, Virginia. SISL works on edge security and traffic resilience for U.S. financial-services and healthcare platforms: bot and abuse mitigation, attack-resilient load balancing, and real-time traffic analytics.

SISL publishes its public research and the open-source core of its software in this organization.

| Repository | Planned content | License |
|---|---|---|
| [regulated-edge-reference-architecture](https://github.com/sovereigninfralab/regulated-edge-reference-architecture) | Reference architecture and implementation guidance for the edge infrastructure of community banks, credit unions and mid-sized health systems | CC BY 4.0 |
| [traffic-analytics-toolkit](https://github.com/sovereigninfralab/traffic-analytics-toolkit) | Open-source core of SISL's traffic-analytics and bot-detection toolkit (working name) | Apache-2.0 |
| [website](https://github.com/sovereigninfralab/website) | Source of the company website | Apache-2.0 (code) |
